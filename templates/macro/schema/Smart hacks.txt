Hack 1: The "Inverted Control" Batch Macro


{# macros/components.html #}
{% macro render_item_batch(items_array, base_url) %}
  {# The macro is called once, creating only 1 stack frame #}
  {% for item_id, item_name in items_array %}
    <div class="item-node" id="node-{{ item_id }}">
      <a href="{{ base_url }}/view/{{ item_id }}">{{ item_name }}</a>
    </div>
  {% endfor %}
{% endmacro %}


{# 1. Pull siteurl ONCE at the top #}
{% set static_url = json_data.siteurl %}

{# 2. Pass the entire collection down in one shot #}
{{ render_item_batch(items_list, static_url) }}


Hack 2: The Context-Inherited {% include %} Partial


{# No macros, no wrappers. It natively hooks into the parent loop variables #}
<div class="card" data-id="{{ item_id }}">
  <span class="title">{{ item_name }}</span>
  <a href="{{ static_url }}/details/{{ item_id }}">View Profile</a>
</div>

{# Pull siteurl ONCE at the top #}
{% set static_url = json_data.siteurl %}

{% for item_id, item_name in items_list %}
  {# Natively passes the current iteration context down at C-level speed #}
  {% include 'partials/_card.html' %}
{% endfor %}



Hack 3: The Flat Tuple Interleaved Speed Run

{# 1. Pull siteurl ONCE at the top #}
{% set static_url = json_data.siteurl %}

{# 2. Imagine flat_data is an ultra-lean tuple: (101, 'Alpha', 102, 'Beta'...) #}
{# We zip the keys and values together instantly using Python C-API slicing #}
{% for id, name in zip(flat_data[::2], flat_data[1::2]) %}
  <div class="fast-row">
    <a href="{{ static_url }}/api/{{ id }}">{{ name }}</a>
  </div>
{% endfor %}


Hack 4: Scoped Block Cache (For Fragment Re-use)


{# 1. Pull siteurl ONCE at the top #}
{% set static_url = json_data.siteurl %}

{# 2. Run the loop exactly ONCE and cache the rendered HTML string #}
{% set cached_elements %}
  {% for item_id, item_name in items_list %}
    <li><a href="{{ static_url }}/{{ item_id }}">{{ item_name }}</a></li>
  {% endfor %}
{% endset %}

<!-- Desktop Viewport Menu -->
<ul class="desktop-menu">
  {{ cached_elements }}
</ul>

<!-- Mobile Viewport Menu (Instant print, 0% recalculation overhead) -->
<div class="mobile-drawer">
  <ul>
    {{ cached_elements }}
  </ul>
</div>





Rank.         Optimization Hack.                        Execution Speed.     Memory Overhead.       Best Structural Use Case

2.        Hack 4: Scoped Block Cache.                   ⚡ Blazing Fast.     🏷️ Low to Medium.      Repeating the exact same code chunk in multiple places on a page.
3.        Hack 1: Inverted Control Batch Macro.         🚀 Very Fast.        🟢 Low.                Standard clean code architecture for large data sets.
